# Server Performance Stats

A lightweight Bash script (`server-stats.sh`) that analyzes basic Linux server performance metrics. Built and tested on Ubuntu Server.


## Features

* **CPU Usage:** Total CPU usage percentage.
* **Memory Usage:** Free vs. used memory with percentage breakdown.
* **Disk Usage:** Free vs. used disk space with percentage breakdown.
* **Top Processes:** Top 5 processes by CPU and Memory usage.
* **System Info:** OS version, uptime, load averages, and logged-in users.
